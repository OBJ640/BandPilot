# Product Requirements

## Purpose

This document explains who will use BandPilot, what problems it will solve, and what features the first version will include.

## Users

### Main Users

- Student bands

### Other Users

- Independent bands
- Small music clubs

The first version will not support orchestras or large music groups because they have more complex needs.

## Problems

### Planning Rehearsals

Band members have different schedules. It is hard to find a time when everyone is free and decide what to practise.

### Tracking Songs

Bands may not know which songs are ready and which parts still need work.

### Remembering Problems

Problems found during rehearsals are easy to forget. The same problems may happen again in the next rehearsal.

### Preparing for Performances

Bands may prepare setlists, equipment, and tasks too late.

## First Version Goal

The first version should let a band:

1. Create a band
2. Add members and songs
3. Track song progress
4. Plan a rehearsal
5. Write feedback after the rehearsal
6. Ask AI for suggestions about the next rehearsal

## Basic Features

### Band Management

Users can:

- Create a band
- Change band information
- Add members
- Add each member's role or instrument

### Song Management

Users can:

- Add and edit songs
- Update song progress
- Record parts that need more practice
- Mark songs as ready or not ready

### Rehearsal Management

Users can:

- Create a rehearsal
- Record when members are free
- Choose songs and goals for the rehearsal
- View past and future rehearsals

### Rehearsal Feedback

Users can:

- Record the songs they practised
- Choose problem types, such as rhythm, teamwork, technique, or tone
- Write notes
- Update song progress

## AI Features

### Rehearsal Plan

AI can use song progress, member availability, performance dates, and past feedback to create a rehearsal plan.

The plan can include:

- Songs to practise first
- Activities for the rehearsal
- Suggested time for each activity

### Feedback Summary

AI can:

- Summarize rehearsal notes
- Find problems that happen many times
- Suggest what the band should practise next

### Performance Help

AI can help the band:

- Arrange a setlist
- Make an equipment checklist
- Make a simple performance plan

## Important Rules

- The first version will be a website that also works on phones.
- The app will use one AI model.
- Users must check AI suggestions before saving them.
- Basic features should still work when AI is not available.
- The first version will use text and form data, not audio analysis.

## Not Included in the First Version

- Audio recording and analysis
- Multiple AI agents
- Social media features
- Music streaming
- Payment systems
- Support for large orchestras

## When the First Version Is Ready

The first version is ready when a real band can:

- Create and manage a band
- Track songs through several rehearsals
- Save and view rehearsal feedback
- Create a useful rehearsal plan with AI
- Make a basic performance checklist
