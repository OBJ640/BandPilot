# BandPilot Vision

## Background

I started a band with my friends when I was 14. Now I am 16, but we still have not finished many songs or performed live.

I found that many student bands have the same problems. Members do not have much free time. It is hard to plan rehearsals, track song progress, and prepare for performances.

BandPilot is my idea for helping bands solve these problems.

## Goal

Build a simple app that helps student bands:

- Plan rehearsals
- Manage members and songs
- Track song progress
- Record rehearsal problems
- Prepare for performances

The app will use AI to give useful suggestions based on the band's information.

## Main Ideas

- The app should be simple and quick to use.
- Basic features should work without AI.
- AI should use real band information when giving suggestions.
- Band members should check AI suggestions before using them.
- The app will use one AI model, not many AI agents.

## Development Plan

### Version 0.1 — Band and Songs

- Create a band
- Add band members
- Add songs
- Update song progress

### Version 0.2 — Rehearsals

- Create rehearsals
- Record member availability
- Add rehearsal goals
- Write feedback after rehearsals

### Version 0.3 — AI Features

- Create rehearsal plans
- Summarize rehearsal feedback
- Find repeated problems
- Suggest what to practise next

### Version 1.0 — First Complete Version

- Finish the main user flow
- Improve the design and user experience
- Test the app with a real band
