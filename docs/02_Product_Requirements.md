# Product Requirements

## Purpose

This document explains who will use BandPilot, what problems it will solve, and what features the first version will include.

## Users

### Main Users

- Student bands

### Other Users

- Independent bands
- Small music clubs

The first version will not support orchestras or large music groups because they have more complex needs.

## Problems

### Planning Rehearsals

Band members have different schedules. It is hard to find a time when everyone is free and decide what to practise.

### Tracking Songs

Bands may not know which songs are ready and which parts still need work.

### Remembering Problems

Problems found during rehearsals are easy to forget. The same problems may happen again in the next rehearsal.

### Preparing for Performances

Bands may prepare setlists, equipment, and tasks too late.

## First Version Goal

The first version should let a band:

1. Create a band
2. Add members and songs
3. Track song progress
4. Plan a rehearsal
5. Complete a short survey for every song after the rehearsal
6. Ask AI for suggestions about the next rehearsal

## Basic Features

### Accounts and First Setup

Users can:

- Create an account and sign in securely
- Stay signed in while using the same browser session
- Sign out from their profile
- Complete a short questionnaire for each band
- Edit the questionnaire when the band's goals or routine change

The questionnaire records the band's genres, experience, main goal, rehearsal routine, and biggest current challenge.

### Band Management

Users can:

- Create a band
- Change band information
- Add members
- Edit and remove members
- Choose each member's musical role from a full list

The musical-role list covers vocals, guitars, rhythm instruments, keyboards, electronic instruments, strings, woodwinds, brass, folk instruments, production, writing, music direction, sound, management, multi-instrumentalist, and other. This is separate from the owner's account permission.

### Song Management

Users can:

- Add and edit songs
- Archive songs without removing their old rehearsal records
- Update song progress with one of five clear levels
- Record parts that need more practice
- Mark songs as ready or not ready

The five progress levels are: Just starting, Learning parts, Can rehearse together, Almost finished, and Performance ready. The app does not ask musicians to guess a percentage.

### Rehearsal Management

Users can:

- Create a rehearsal
- Edit or cancel a planned rehearsal
- Record when members are free
- Choose songs and goals for the rehearsal
- View past and future rehearsals

### Post-Rehearsal Survey

Users can:

- Give the whole rehearsal a rating from 1 to 5
- Record whether the rehearsal goals were met
- Select the songs that were practised
- Review each selected song separately
- Give each song a rating from 1 to 5
- Choose a problem type, such as rhythm, coordination, technique, tone, or memory
- Write a short note for each song
- Update each song's five-level progress and status
- View old song reviews and filter them by song or problem type

The band owner can save or edit the survey. Band members can view the saved result. Saving the survey marks the rehearsal as completed.

## AI Features

### Rehearsal Plan

AI can use song progress, member availability, performance dates, and past rehearsal surveys to create a rehearsal plan.

The plan can include:

- Songs to practise first
- Activities for the rehearsal
- Suggested time for each activity

### Survey Summary

AI can:

- Summarize post-rehearsal survey notes
- Find problems that happen many times
- Suggest what the band should practise next

### Performance Help

AI can help the band:

- Arrange a setlist
- Make an equipment checklist
- Make a simple performance plan

## Important Rules

- The first version will be a website that also works on phones.
- The app will use one AI model.
- Users must check AI suggestions before saving them.
- Basic features should still work when AI is not available.
- The first version will use text and form data, not audio analysis.

## Not Included in the First Version

- Audio recording and analysis
- Multiple AI agents
- Social media features
- Music streaming
- Payment systems
- Support for large orchestras

## When the First Version Is Ready

The first version is ready when a real band can:

- Create and manage a band
- Track songs through several rehearsals
- Save and view a separate review for every song practised in a rehearsal
- Create a useful rehearsal plan with AI
- Make a basic performance checklist
